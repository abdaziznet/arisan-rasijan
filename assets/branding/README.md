# BANI RASIJAN logo system

The mark is a dynamic **Rasijan R** monogram for **Bani Rasijan**. It features a bold white geometric 'R' cut across an emerald green canvas, symbolizing family strength, modern continuity, and heritage.

## Source-of-truth alignment

- Brand: **BANI RASIJAN** — *Arisan Keluarga*
- Category: private family arisan companion
- Audience: extended family, including parents and elders
- Primary: deep emerald green `#0E7449` (supporting primary: `#0F766E`)
- Accent: warm gold `#D99A2B` (celebrations / winners)
- Background: `#F8FAFC`; surface: `#FFFFFF`
- Type: Plus Jakarta Sans; fallback Inter / system sans serif
- Master Asset: `assets/image/Rasijan.png`

## Files

- `bani_rasijan_app_icon.svg` — primary Play Store / launcher artwork, 1:1.
- `bani_rasijan_symbol.svg` — standalone Rasijan 'R' monogram vector.
- `bani_rasijan_lockup_horizontal.svg` — light-background horizontal lockup.
- `bani_rasijan_lockup_vertical.svg` — light-background vertical lockup.

## Usage

Keep the logo centered with adequate safe margin when generating Android adaptive icons or iOS app icons.
