# BANI RASIJAN

Private mobile application for family arisan, contributions, gatherings, and shared family records.

## Current milestone

The first vertical slice implements the centralized design system, reusable foundation components, primary navigation, Splash, Login interface, and Home interface.

The login transition is local presentation-only until a Supabase project URL, anon key, and mobile deep-link redirect settings are supplied. It must not be treated as authenticated access.
