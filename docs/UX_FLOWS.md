# UX Flows

## Initial vertical slice

Splash opens the branded entry point, then routes to email login. After a valid email is entered, the prototype presents the member home. Production authentication will replace this local transition with Supabase Email OTP/Magic Link after Supabase project credentials and redirect configuration are available.

## Pending detailed flows

Invite member, payment, donation, arisan lifecycle, digital draw, gathering fund, voting, gathering completion, photo upload, and offline/retry will be documented before their respective implementation phases.
